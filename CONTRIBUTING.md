# Contributing to NHL 92 Genesis

This is a bit-perfect disassembly of NHL Hockey 92 for the Sega Genesis. It builds the retail ROM (`REV=0`) and Rev A (`REV=1`) from one source. It is the root of the family: NHLPA 93, NHL 94, 95 and 96 Genesis and the two SNES ports use its names and its comments. Read [README.md](README.md) first for how to build.

## 1. 92 is the reference

- The names, comments and layout of the EA source are kept as they are, including typos and odd capitalisation. Do not rename, reword, shorten or reformat them. The later games copy them and are compared against them.
- Changes are limited to the build scripts, `docs/`, and `src/sound/sound.asm` (the disassembly that is not EA's own source). Anything else needs the maintainer's say-so first.
- A factual error in an EA comment is reported in the pull request, not fixed in place.

## 2. Every build must still match

The code, data and bytes must not change unless the change is the point of the PR. Before every push:

```
tools/verify_all.sh -q
```

It builds retail and Rev A and compares each with its ROM (`nhl92retail.bin` and `nhl92retailRevA.bin` in the repo folder, see the README). Code that differs between the revisions is inside `IF REV=...` blocks. Never commit ROMs, `Extracted/` or `output/`.

## 3. sound.asm

- Data the driver reads is written as `label-p_music_vblank` (the offsets `Sound_WriteYM2612` takes are distances from `p_music_vblank`), not as numbers.
- New names follow the later games' scheme: a descriptive name that is not already used for something else. Record a rename in the pull request.
- Comments say what the code does. Describe the instructions when the purpose is not clear, or write "probably"; do not guess.

## 4. Comment layout for new comments

- Indent with tabs; a tab is 4 columns.
- A trailing comment starts at column 36, or one tab after code that reaches column 36.
- No comment line is wider than 110 columns. A longer comment continues on the next lines, starting in the same column.
- A header or block comment has paragraphs of at most 3 lines, separated by a `;` line, and does not list every routine in order.

## 5. Commits and pull requests

- One topic per branch and pull request; small commits. Branch from `main`.
- The pull request says what changed and that both builds match.
- Merge with a merge commit, not a squash.
- After a merge the report at abdulahmad/nhl-disasm-report is regenerated by the maintainer.
- A change that affects names or conventions shared with the later games is made there too, starting from 92.

## 6. Checklist

- [ ] `tools/verify_all.sh` matches for retail and Rev A
- [ ] no EA name or comment was changed
- [ ] new comments follow the layout above
